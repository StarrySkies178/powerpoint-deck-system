# Open-book mimic brief: C09-sensitivity-truenorth

Roadmap 4.2, the open-book mimic test (v2.72). Unlike the blind benchmark, you SEE the slide you must reproduce. This is how the system is used for real: the user gives a slide and asks for it as PowerPoint.

**Given to you:**
- The original slide as PowerPoint draws it: `bench/mimic/C09-sensitivity-truenorth/original-1920.png` (1920 px wide, from PowerPoint's PDF) and `bench/mimic/C09-sensitivity-truenorth/original.png` (the same at 1280 px, the picture the score compares with). Look at it closely (crop and zoom with python into your own /tmp folder).
- Its text and numbers: `bench/cases/C09-sensitivity-truenorth/prompt.md`.
- The reference deck's style profile: `Style/refs/Case-2016-TrueNorth-Pola-China-growth.profile.json` (`L.start({ ref: "Case-2016-TrueNorth-Pola-China-growth" })` in the harness applies it).
- The slide's own stored objects in `Objects/store/case-truenorth-pola.jsonl.gz`: ids starting with `case-truenorth-pola-022` (`case-truenorth-pola-022`). Read `Objects/README.md` and `Generators/objstore.py` for find / place / set_texts / set_chart_data / extend / recolour / `colours="original"`. You may place these objects, any other stored object of the deck, and the framework's generators, in any mix.
- `DECK-SYSTEM.md` and `bench/lib/bench_lib.js` (the harness: `L.start`, `L.save`).

**Deliver two builds, each as native, editable PowerPoint shapes (text boxes, shapes, native tables or charts). No picture of the slide or of any part of it (a chart, a map, a table, text) may be embedded: pictures are allowed only for elements that are pictures in the original deck (a logo, an icon, a photo).**
1. **Build A, same content:** `bench/mimic/C09-sensitivity-truenorth/A/build.js` (and `build.py` if needed, run after build.js with A/ as working directory) writing `bench/mimic/C09-sensitivity-truenorth/A/candidate.pptx`. Make it look as much like the original as you can: same layout, same exhibits drawn the same way, same colours, sizes, labels and positions. Render it (LibreOffice with your own profile: `soffice -env:UserInstallation=file:///tmp/lo_mimic_C09A --headless --convert-to pdf ...`, then `pdftoppm -r 96`) and compare with original.png side by side; iterate until it matches as closely as you can get.
2. **Build B, changed content, from the same objects:** `bench/mimic/C09-sensitivity-truenorth/B/build.js` (+ `build.py`) writing `bench/mimic/C09-sensitivity-truenorth/B/candidate.pptx`. Same design, but invent different content: other numbers and labels throughout, and **one item more or one item fewer** where the form allows (for example a tenth year or a third scenario chart). This proves the objects are reusable, not a pasted picture. Render and check it too.
3. **`bench/mimic/C09-sensitivity-truenorth/report.md`** (short, plain): which stored objects you placed (ids) and how (as is, refilled, extended, recoloured); what you redrew instead and why; for B, what you changed and anything that broke or needed manual fixing when the content changed. Run `scripts/deck_lint.py <candidate> --profile Style/refs/Case-2016-TrueNorth-Pola-China-growth.profile.json` on both and give the counts.

**Rules:** write only inside `bench/mimic/C09-sensitivity-truenorth/`; change no framework file (Generators, scripts, Objects, Style); do not use git; do not open `bench/cases/` except `bench/cases/C09-sensitivity-truenorth/prompt.md`, and do not open other folders of `bench/` except this case's mimic folder. If placing a stored object fails for a real reason (a bug in objstore, a broken object), work around it and describe the failure exactly in report.md.
