# skill/

`deck-system/SKILL.md` is the master copy of the Claude skill that points at this folder. It follows the open SKILL.md format, so other agents that read skills can use the same file.

- The skill saved in the user's Claude account should be identical to this file. On 2026-11-24 (v2.23) it was: this copy was taken from the saved skill (sha256 `c7b1423681c24b866f7fba4e3d915b0b5a57684124ddf8dd55201970411838b7`). When in doubt, compare the two texts.
- The skill is a pointer and should rarely change. To change it: edit this file through the normal learning loop, then propose the same change to the user as a skill card. Only the user can save a skill.
- Never put rules in the skill. Rules live in the folder files it points to.
